📄 סקיל להגהת דוחות כספיים

סקיל של Claude שעובר על דוח כספי לפני שליחתו ללקוח ומפיק דוח ממצאים באקסל.

הורדה

הורדת הסקיל (ZIP)
כתיב ודקדוקטרמינולוגיה חשבונאיתמבנה וסדר ביאורים גילויים נדרשיםאימות מספריעסק חי

עובד גם על דוח סרוק. הפלט: הגהה_[לקוח]_[שנה].xlsx, טיוטה לבדיקת אדם לפני שליחה ללקוח.
גרסה 1.1.1 · אוקטובר 2026

התקנה והפעלה

  1. מורידים את קובץ ה-ZIP.
  2. בהגדרות של Claude נכנסים אל Customize > Skills > Add > Upload skill ומעלים את ה-ZIP כמו שהוא, בלי לחלץ. הסקיל נשמר בחשבון וזמין בכל הסביבות.
  3. מצרפים לשיחה את ה-PDF של הדוח, או פותחים את התיקייה שבה הוא נמצא, וכותבים תעבור הגהה על הדוח.

ב-claude.ai וב-Cowork אין צורך להתקין דבר נוסף. רק ב-Claude Code על המחשב נדרש פעם אחת Python, ואחריו pip install pymupdf openpyxl.

🔒 סודיות: הסקיל גנרי וללא נתוני לקוח. קובץ ההגהה שהוא מפיק הוא מידע לקוח, ואין להעלותו לאתר ציבורי או לשירות חיצוני. שימוש פנימי בלבד, כפוף לסודיות מקצועית.
