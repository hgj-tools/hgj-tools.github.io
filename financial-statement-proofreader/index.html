📄 כלי הגהת דוחות כספיים

סקיל של Claude שעובר על דוח כספי עמוד אחר עמוד לפני שליחתו ללקוח, ומפיק דוח ממצאים באקסל.

🤖 זהו סקיל של Claude, לא כלי דפדפן. מורידים את החבילה, מטעינים ל-Claude, ומצביעים על ה-PDF של הדוח.

הורדה

הורדת החבילה (ZIP)
כתיב ודקדוקטרמינולוגיה חשבונאיתמבנה וסדר ביאורים גילויים נדרשיםאימות מספריעסק חי

הכלי קורא את העמודים ויזואלית, כתמונות, משום שחילוץ טקסט מ-PDF עברי אינו אמין ומשמיט אותיות בשקט. לצד בדיקת הניסוח הוא מאמת עצמאית כל סכום וסיכום ביניים. הפלט: הגהה_[לקוח]_[שנה].xlsx בשלושה גיליונות. זו טיוטה לבדיקת אדם לפני שליחה ללקוח.

התקנה והפעלה

1. הטענת הסקיל

בתפריט ההגדרות: Customize > Skills > Add > Upload skill, ומעלים את קובץ ה-ZIP כמו שהוא, בלי לחלץ ובלי לארוז מחדש. הסקיל נשמר בחשבון ומופיע בכל הסביבות, כולל Claude Code.

שים לב: הסקילים יושבים תחת Customize, ולא תחת Capabilities, אף ששם דומה מופיע גם הוא בתפריט.

2. Python

נדרש Python 3 בסביבה שבה Claude מריץ קוד (ראה ההסבר למטה). אם אין, מתקינים מהמקור הרשמי ומסמנים בהתקנה Add python.exe to PATH:

הורדת Python (python.org)

ואז פעם אחת בשורת הפקודה:

pip install pymupdf openpyxl

3. הפעלה

פותחים שיחה בתיקייה שבה נמצא ה-PDF ומבקשים תעבור הגהה על הדוח. קובץ האקסל נכתב לצד הדוח.

⚠ מה רץ ולמה צריך Python. החבילה איננה הנחיות בלבד. בתוכה שני סקריפטים שמורצים בפועל: אחד ממיר כל עמוד ב-PDF לתמונה, והשני בונה את קובץ האקסל המעוצב. הקריאה של העמודים והשיפוט המקצועי הם של Claude, אבל שני השלבים המכניים הם קוד, והוא רץ בסביבה שבה Claude מריץ קוד. ב-Claude Desktop וב-Claude Code זה המחשב שלכם, ולכן Python צריך להיות מותקן שם. בסביבת הרצה בענן אין רשת ו-PyMuPDF אינו מותקן, ולכן שלב המרת העמודים לתמונות ייכשל שם.
🔒 סודיות: החבילה עצמה גנרית וללא נתוני לקוח. תוצרי הריצה (קובץ ההגהה ותמונות העמודים) הם מידע לקוח ונשארים על המחשב שלכם בלבד. אין להעלותם לרשת או לשירות חיצוני. שימוש פנימי בלבד, כפוף לסודיות מקצועית.
